# Changelog

## [0.1.0] — Initial Release

### Added

- OWASP Top 10 (2021) rules for JavaScript/TypeScript, Python, and PHP
- Content Security Policy analysis rules
- General secure-coding rules (hardcoded secrets, insecure TLS, prototype pollution, XXE, ReDoS, etc.)
- Real-time inline diagnostics with severity levels (Critical / Warning / Info)
- Security Report webview panel
- Quick Fix code actions: auto-fix, suppress, and open reference docs
- Workspace-wide scan command
- Configurable severity threshold and rule ignore list
